🎓 About This College Mini-Project

Academic Showcase

Smart Expense Tracker is a client-side personal finance manager. It demonstrates core web development fundamentals: Semantic HTML5 structure, Modern CSS Flexbox & Grid design system, and Vanilla JavaScript (ES6) for state management, dynamic DOM rendering, real-time filtering, mathematical aggregation, and persistence using the browser's localStorage API.

✓ 100% Client-side ✓ No Backend Required ✓ Instant LocalStorage Sync ✓ Responsive Design ✓ Input Validation & Error Prevention ✓ CSV Export
